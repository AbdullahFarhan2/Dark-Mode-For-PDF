# PDF Dark Reader

A lightweight Chrome extension that applies a dark theme to PDF documents for a more comfortable reading experience.

## Features

- Dark mode for PDFs
- Designed specifically for PDF documents
- Lightweight and simple
- No account or external service required
- Easy-to-use popup controls

## Installation

1. Download or clone this repository.
2. Open Chrome and go to `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the extension folder.
